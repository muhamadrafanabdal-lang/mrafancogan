01 — Persiapan

Alat & Bahan

Siapkan seluruh peralatan berikut sebelum melakukan perakitan kabel LAN.

🔌

Kabel UTP

Kabel jaringan yang digunakan sebagai media penghantar data antar perangkat.

🔗

RJ45

Konektor yang dipasang pada ujung kabel UTP agar dapat terhubung ke port Ethernet.

✂️

Tang Crimping

Digunakan untuk memotong kabel dan mengunci kabel UTP pada konektor RJ45.

🧪

LAN Tester

Digunakan untuk mengecek apakah susunan kabel dan koneksi RJ45 sudah benar.

02 — Perakitan

Cara Merangkai Kabel LAN

Ikuti langkah berikut secara berurutan agar kabel crossover dapat digunakan untuk koneksi peer to peer.

01

Kupas Kabel UTP

Gunakan stripper atau bagian pemotong pada tang crimping untuk mengupas lapisan luar kabel UTP. Jangan sampai merusak kabel-kabel kecil di dalamnya.

02

Susun Kabel Sesuai Standar

Untuk membuat kabel crossover, gunakan susunan T568B pada satu ujung dan T568A pada ujung lainnya.

03

Ratakan Ujung Kabel

Potong ujung kabel agar semua inti kabel memiliki panjang yang sama dan mudah dimasukkan ke RJ45.

04

Masukkan ke RJ45

Masukkan delapan kabel ke konektor RJ45 sesuai urutan warna. Pastikan semua kabel masuk sampai bagian ujung konektor.

05

Crimping RJ45

Masukkan RJ45 ke tang crimping kemudian tekan dengan kuat sampai pin konektor mengunci kabel.

06

Uji dengan LAN Tester

Hubungkan kedua ujung kabel ke LAN Tester. Pastikan indikator menyala sesuai urutan pin dan tidak ada kabel yang bermasalah.

04 — Peer to Peer

Menghubungkan 2 Laptop

Hubungkan dua laptop secara langsung menggunakan kabel LAN crossover.

🔗 Hubungkan Perangkat

  • 1. Siapkan dua laptop.
  • 2. Hubungkan kabel crossover ke port Ethernet Laptop 1 dan Laptop 2.
  • 3. Pastikan lampu indikator Ethernet menyala.
  • 4. Atur IP Address secara manual pada kedua laptop.

⚙️ Pengaturan Windows

  • 1. Control Panel
  • 2. Network and Internet
  • 3. Network and Sharing Center
  • 4. Change adapter settings
  • 5. Klik kanan Ethernet → Properties
  • 6. Internet Protocol Version 4 (TCP/IPv4)

🌐 Pengaturan IP Address

Gunakan alamat IP berikut agar kedua laptop berada pada jaringan yang sama.

Perangkat IP Address Subnet Mask
Laptop 1 10.10.10.1 255.0.0.0
Laptop 2 10.10.10.2 255.0.0.0

💻 Tes Koneksi dengan CMD

Tekan Windows + R, ketik cmd, lalu tekan Enter. Pada Laptop 1 jalankan:

ping 10.10.10.2

Jika muncul pesan Reply from 10.10.10.2, berarti kedua laptop berhasil berkomunikasi.

05 — File Sharing

Sharing File Antar Laptop

Bagikan folder atau dokumen dari satu laptop ke laptop lainnya melalui jaringan LAN.

01. Pilih Folder

Klik kanan folder yang ingin dibagikan, kemudian pilih Properties.

02. Aktifkan Sharing

Pilih tab Sharing kemudian klik Advanced Sharing dan aktifkan Share this folder.

03. Akses dari Laptop 2

Buka File Explorer dan masukkan alamat:

\\10.10.10.1

💡 Tips Sharing File

  • Pastikan kedua laptop terhubung dengan kabel LAN.
  • Pastikan IP Address berada dalam jaringan yang sama.
  • Aktifkan Network Discovery.
  • Aktifkan File and Printer Sharing.
  • Pastikan Windows Firewall tidak memblokir koneksi jaringan lokal.
